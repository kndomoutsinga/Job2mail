Nouvelle recherche

Cherche des entreprises actives via l'API Sirene pour une ville (ou un code postal), un département, une région, ou la France entière, combinés à des codes NAF donnés, essaie de deviner leur site web, puis cherche un contact via Hunter.io si une clé API est configurée. Un brouillon de mail est créé pour chaque entreprise où un contact a été trouvé. Vous pouvez aussi chercher une entreprise précise par son nom, quel que soit son secteur, plutôt que par zone géographique/NAF.

Renseignez au moins un nom d'entreprise, une ville, un département, une région, ou "France" pour tout le pays. Un département ou une région couvre d'un coup toutes ses villes (pas besoin de les connaître/lister à l'avance) ; ces champs se combinent avec les codes NAF ci-dessous mais pas forcément avec la Ville/le Code postal.
